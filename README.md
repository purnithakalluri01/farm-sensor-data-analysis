# Student Performance Analysis and Prediction Using R

## Project Overview
This project analyzes student academic performance using R and RStudio and predicts a final score using multiple linear regression.

## Objectives
- Inspect and summarize student performance data.
- Check for missing values.
- Visualize score distribution and relationships.
- Calculate correlations.
- Build a multiple linear regression model.
- Predict a final score for a hypothetical student.

## Variables
- `Student_ID`
- `Study_Hours`
- `Attendance_Percent`
- `Assignment_Average`
- `Previous_Score`
- `Final_Score`

## Requirements
- R 4.x
- RStudio

## How to Run
Open the repository as an RStudio project, open `R/student_performance_analysis.R`, and run the script.

The script creates the dataset, performs descriptive analysis, generates graphs, calculates correlations, fits the regression model, and prints the final prediction.
